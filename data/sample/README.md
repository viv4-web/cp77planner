# SAMPLE data

Everything in this folder is **SAMPLE** data for layout work only (the perk trees). Names, requirements, point
rules and descriptions are placeholders and are not game facts. Real data will be generated from game-file exports.
Cyberware is no longer sample: see `data/cyberware.json` and `docs/GAME-DATA.md`.

`n` is the permanent numeric alias of a record ID used by the URL codec. Never reuse or renumber.
